# EDQI Enterprise Analytics Reports Directory

This folder holds automatically generated performance dashboards, research diagnostic benchmarks, health logs, version indexes, and manifest summaries.

## Layout Mapping
- `manifests/`: unified manifest tags
- `performance/`: execution trace metric trends and comparisons
- `research/`: hardware diagnostics and IEEE result files
- `statistics/`: executive project metrics summaries
- `health/`: platform quality scoring trends
- `drift/`: dataset covariance and KS distribution shifts
- `datasets/`: dataset evolution histories
- `training/`: supervised estimators performance metrics
